    요일 리듬 수집 현황

    보드를 연 날짜가 자동 기록됩니다

    브런치 장사의 진짜 질문은 "주말 곡선이 평일과 얼마나 다른가"입니다. 요일별 관측이 쌓이면 준비량 기준이 생깁니다.

    이 보드는 무엇인가

    제이드앤워터 성수 LCDC점을 위한 아침 운영 대시보드입니다. 서울시가 공개하는 성수카페거리 실시간 데이터(유동인구·카드소비·날씨·예측)를 이 파일이 직접 받아와, "오늘 얼마나 준비할지"와 "몇 시가 승부처인지"를 한 화면으로 보여줍니다. 설치·서버·구독이 전혀 없고, 이 HTML 파일 하나로 동작합니다.

    처음 한 번 — 인증키 발급 (약 5분, 무료)

    1. 1data.seoul.go.kr(서울 열린데이터광장) 회원가입 후 로그인
    2. 2마이페이지 → 인증키 신청 → "일반 인증키" 발급 (사용 용도는 간단히 적으면 됩니다)
    3. 3발급된 키를 복사해 보드 상단 [키] 버튼 → 입력창에 붙여넣고 [저장하고 불러오기]

    키는 이 컴퓨터의 이 브라우저에만 저장됩니다. 다른 컴퓨터·폰에서 열면 그 기기에서 한 번 더 넣어야 합니다.

    매일 아침 — 여는 법과 읽는 순서

    1. 1파일을 더블클릭해 엽니다. 이후 10분마다 자동 갱신되고, [지금 갱신]으로 즉시 새로고침할 수 있습니다.
    2. 2판단 배지부터 봅니다 — "준비량 유지"면 평소대로, "증량 검토"로 바뀌면 재료·인력 여유분 점검.
    3. 3오늘 시간대별 날씨 — 노란 테두리(브런치 창 10–15시)에 파란 칸(강수확률 50%↑)이 있으면 우산·실내 회전 준비.
    4. 4수요 곡선 — 옥색 점선(오늘 예측)이 회색 밴드(월요일 기준선)보다 높으면 평소보다 붐비는 날입니다.
    5. 5필요할 때 오늘의 조언과 나머지 섹션을 참고합니다.

    각 섹션 읽는 법

    실시간 상권 신호
    거리 유동인구·혼잡도·10분 카드소비. "직전 관측 대비"는 이 보드가 직접 계산한 증감률입니다.
    오늘 다녀간 사람
    갱신 때마다 거리 인구 구성을 누적한 오늘 하루의 방문객 프로필. 사람이 많던 시간대가 더 무겁게 반영됩니다. 저녁에 볼수록 정확해집니다.
    성수 자가 급증 감지
    약 45분 전 관측 대비 인구 +20% 또는 소비 +30%면 ▲ 표시와 함께 상단 판단이 '증량 검토'로 자동 전환됩니다.
    핫플 실시간 비교
    서울숲·연남동·압구정로데오·홍대와 지금 이 순간의 유동인구를 비교합니다. 성수 줄이 옥색입니다.
    수요 곡선·시뮬레이터
    옥색 블록이 영업시간(기본 09–17시). 블록 경계를 드래그하거나 +/− 버튼으로 바꾸면 "영업 중 평균 유동"이 다시 계산됩니다. 마감 연장을 검토할 때 쓰세요. 조정값은 자동 저장됩니다.
    지금 거리의 100명
    현재 순간의 거리 인구 100명 환산. 연령/사는 곳/성별 탭 전환.
    경쟁 지형
    업종별 카드 가맹점 수 트리맵. 면적이 클수록 그 업종 가게가 많다는 뜻입니다.
    안내문
    [안내문 복사] 버튼 → 인스타 프로필·네이버 플레이스·예약 확인 문자에 그대로 붙여넣기.
    요일 리듬
    보드를 연 요일이 자동 기록됩니다. 일주일을 채우면 요일별 감이 생깁니다.

    이 숫자를 믿어도 되는 범위

    • 유동·소비는 성수카페거리 전체 기준입니다 — 우리 매장 방문객 수가 아니라 상대 비교용입니다.
    • 카드소비는 10분 스냅샷이라 표본이 작습니다. 한 번의 수치보다 추세를 보세요.
    • 곡선의 회색 밴드는 2026-08-31(월) 수집 기준선입니다. 주말은 다르게 움직입니다 — 옥색 점선(오늘 예측)을 우선하세요.

    문제가 생기면

    "갱신 실패"
    ① 키 오타 확인([키] 버튼) ② 인터넷 연결 확인 ③ 회사·기관 보안망이 http 요청을 막는 경우가 있습니다 — 휴대폰 핫스팟으로 열어 확인해 보세요.
    키를 바꾸고 싶다
    상단 [키] 버튼 → 새 키 입력 → 저장.
    누적 기록 초기화
    브라우저 설정에서 "사이트 데이터 삭제"를 하면 키·영업시간·누적 관측이 모두 지워집니다(파일 자체는 무관).
    비교 핫플·갱신 주기 변경
    파일을 메모장으로 열어 상단 CONFIG의 COMPARE 목록과 INTERVAL_MIN을 수정하면 됩니다.
    완전 독립 실행형 — 이 파일 하나로 동작합니다. 데이터는 서울시 열린데이터광장 citydata API를 브라우저에서 직접 호출(중계 서버·MCP 없음), 인증키·관측 이력은 이 브라우저에만 저장됩니다.
